DEPLOYMENT
1. Upload every file in this folder to the HTTPS document root of arthasetu.in.
2. Keep .htaccess at the document root when using Apache hosting.
3. Keep the extensionless calculator files exactly as named. Apache is instructed to serve them as HTML.
4. Confirm the nine calculator URLs return HTTP 200 and display one calculator workspace.
5. Confirm https://arthasetu.in/ redirects to /income-tax.
6. Submit https://arthasetu.in/sitemap.xml in Google Search Console and inspect each calculator URL.
7. Test both mobile and desktop layouts and browser Back/Forward navigation.
8. If your host does not support Apache .htaccess, configure the same clean routes as static HTML files in the hosting control panel/server.
